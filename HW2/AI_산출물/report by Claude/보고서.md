## 문제 1. BST insert (5, 3, 7, 8, 2, 9, 1)

### 1-1. 해답 — 단계별 도식

각 단계에서 새 키가 추가되는 경로를 표시한다.

```
[Step 1] insert 5             [Step 2] insert 3            [Step 3] insert 7
    5                              5                              5
                                  /                              / \
                                 3                              3   7

[Step 4] insert 8             [Step 5] insert 2            [Step 6] insert 9
    5                              5                              5
   / \                            / \                            / \
  3   7                          3   7                          3   7
       \                        /     \                        /     \
        8                      2       8                      2       8
                                                                       \
                                                                        9

[Step 7] insert 1 — 최종 BST
    5
   / \
  3   7
 /     \
2       8
/        \
1         9
```

### 1-2. 핵심 기능 요약

- 이진 탐색 트리(BST)의 삽입은 루트부터 비교하며 좌(작음)·우(큼) 자식으로 내려가서 빈 위치에 새 노드를 붙이는 연산이다.
- 평균 시간복잡도 O(log n), 최악(편향) O(n).
- 본 시퀀스는 좌측·우측 모두로 길게 뻗어 균형이 잡히지 않은 BST의 전형적 형태를 만든다.

### 1-3. 출제 의도

- BST의 정의(좌소우대) 이해.
- 입력 순서에 따라 트리 모양과 높이가 결정됨을 체감.
- 4·5번에서 비교할 AVL 트리와의 차이를 만들기 위한 기반 트리 구성.

### 1-4. Claude 자체 부여 sub-prompt

```
빈 이진 탐색 트리(BST)에 다음 키를 순서대로 삽입한다:
(5, 3, 7, 8, 2, 9, 1)

각 삽입 단계마다 트리 모양을 텍스트 도식으로 보여주고,
최종 트리의 in-order / pre-order / post-order 순회 결과를 출력하라.
```

### 1-5. Claude 결과 (요약)

- 최종 트리: 위 [Step 7] 도식과 동일.
- In-order:   `1 2 3 5 7 8 9`
- Pre-order:  `5 3 2 1 7 8 9`
- Post-order: `1 2 3 9 8 7 5`

## 문제 2. BST delete (1, 2, 5, 8, 9)

### 2-1. 해답 — 단계별 도식

문제 1의 최종 BST에서 시작한다. `bintrees.BinaryTree.remove()`는 두 자식이 있는 노드 삭제 시 **in-order successor**(우측 서브트리의 최솟값)로 대체한다.

```
[시작] 문제 1 최종           [Step 1] delete 1 (leaf)
    5                              5
   / \                            / \
  3   7                          3   7
 /     \                        /     \
2       8                      2       8
/        \                              \
1         9                              9

[Step 2] delete 2 (leaf)     [Step 3] delete 5 (root, 두 자식)
    5                            7              ← 5를 in-order successor 7로 교체
   / \                          / \
  3   7                        3   8
       \                            \
        8                            9
         \
          9

[Step 4] delete 8 (자식 1개) [Step 5] delete 9 (leaf) — 최종
    7                              7
   / \                            /
  3   9                          3
```

### 2-2. 핵심 기능 요약

- BST 삭제는 노드의 자식 수에 따라 세 가지 경우로 나뉜다.
  1. 자식 없음(leaf): 단순 제거.
  2. 자식 1개: 자식을 노드 위치로 끌어올림.
  3. 자식 2개: in-order successor(또는 predecessor)와 키를 교체하고 successor를 재귀적으로 삭제.
- `bintrees`는 in-order successor 방식을 사용한다.

### 2-3. 출제 의도

- 자식 수에 따른 삭제 케이스 분기를 직접 추적.
- 루트 삭제(5번 단계)에서 successor 치환 과정을 이해.
- 동일 삭제 시퀀스를 AVL에서 적용했을 때(4번 문제)와 비교할 기준 마련.

### 2-4. Claude 자체 부여 sub-prompt

```
문제 1에서 만든 BST에서 다음 키를 순서대로 삭제한다:
(1, 2, 5, 8, 9)

두 자식이 있는 노드는 in-order successor로 대체하라(bintrees 규약).
각 삭제 단계의 트리 모양을 도식화하고, 최종 트리의 세 가지 순회 결과를 출력하라.
```

### 2-5. Claude 결과 (요약)

- 최종 트리: 루트 `7`, 좌 자식 `3`만 남음.
- In-order:   `3 7`
- Pre-order:  `7 3`
- Post-order: `3 7`

## 문제 3. AVL insert (5, 3, 7, 8, 2, 9, 1)

### 3-1. 해답 — 단계별 도식 (BF = balance factor = height(L) − height(R))

```
[Step 1] insert 5            [Step 2] insert 3            [Step 3] insert 7
    5 (BF=0)                       5 (BF=1)                       5 (BF=0)
                                  /                              / \
                                 3                              3   7

[Step 4] insert 8                              [Step 5] insert 9 → BF(7)=-2 (RR)
    5 (BF=-1)                                       5 (BF=-2)
   / \                                              / \
  3   7 (BF=-1)                                    3   7 (BF=-2)
       \                                                \
        8                                                8
                                                          \
                                                           9
            ↓ left-rotate(7)
[Step 5 after rotation]
    5 (BF=-1)
   / \
  3   8 (BF=0)
     / \
    7   9

[Step 6] insert 2            [Step 7] insert 1 → BF(3)=2 (LL case)
       5 (BF=0)                       5 (BF=1)
      / \                            / \
     3   8                          3   8        (BF(3)=2, BF(2)=1)
    /   / \                        /   / \
   2   7   9                      2   7   9
                                 /
                                1
                                          ↓ right-rotate(3)
[Step 7 after rotation] — 최종 AVL
       5
      / \
     2   8
    / \ / \
   1  3 7  9
```

### 3-2. 핵심 기능 요약

- AVL 트리는 모든 노드의 BF가 `{-1, 0, +1}`에 들어가도록 회전을 통해 균형을 유지하는 BST이다.
- 4가지 회전 케이스:
  - LL: 우회전 1회
  - RR: 좌회전 1회
  - LR: 좌-우 이중 회전
  - RL: 우-좌 이중 회전
- 본 시퀀스에서는 두 번의 단일 회전이 발생한다.
  - Step 5: 노드 7에서 RR → 좌회전
  - Step 7: 노드 3에서 LL → 우회전

### 3-3. 출제 의도

- BST 삽입에 회전 보정이 결합된 AVL 알고리즘 이해.
- 동일 입력 시퀀스 대비 BST 대비 AVL이 어떻게 균형 잡힌 트리를 만드는지 비교.
- LL과 RR 두 케이스를 한 시퀀스에서 경험.

### 3-4. Claude 자체 부여 sub-prompt

```
빈 AVL 트리에 다음 키를 순서대로 삽입한다:
(5, 3, 7, 8, 2, 9, 1)

각 삽입 직후 BF(balance factor)를 계산하고, 불균형이 발생하면 회전 종류(LL/LR/RL/RR)와
회전 후 트리를 도식으로 보여라. 최종 트리의 세 가지 순회 결과도 출력하라.
```

### 3-5. Claude 결과 (요약)

- 회전 발생: Step 5에서 좌회전(RR), Step 7에서 우회전(LL).
- 최종 트리: 완전히 균형 잡힌 높이 3의 트리.
- In-order:   `1 2 3 5 7 8 9`
- Pre-order:  `5 2 1 3 8 7 9`
- Post-order: `1 3 2 7 9 8 5`

## 문제 4. AVL delete (1, 2, 5, 8, 9)

### 4-1. 해답 — 단계별 도식

문제 3의 최종 AVL에서 시작한다. 삭제 후 BF가 깨지면 가까운 조상에서 회전 보정을 수행한다.

```
[시작] 문제 3 최종           [Step 1] delete 1 (leaf)
       5                          5
      / \                        / \
     2   8                      2   8        (BF(2)=-1, BF(5)=0, BF(8)=0, OK)
    / \ / \                      \  / \
   1  3 7  9                      3 7  9

[Step 2] delete 2 (자식 1개) [Step 3] delete 5 (root, 두 자식)
       5                          7              ← in-order successor 7로 교체
      / \                        / \
     3   8                      3   8
        / \                          \
       7   9                          9

   Step 2 직후 BF: BF(3)=0, BF(8)=0, BF(5)=-1 — 회전 불필요.
   Step 3 직후 BF: BF(8)=-1, BF(7)=-1 — 회전 불필요.

[Step 4] delete 8 (자식 1개) [Step 5] delete 9 (leaf) — 최종
       7                          7
      / \                        /
     3   9                      3

   Step 4 직후 BF: BF(7)=0 — 회전 불필요.
   Step 5 직후 BF: BF(7)=1 — 회전 불필요.
```

### 4-2. 핵심 기능 요약

- AVL 삭제는 BST 삭제와 동일한 케이스 분기를 수행한 뒤, 영향받은 경로의 BF를 점검하여 필요 시 회전한다.
- 본 시퀀스에서는 삭제 직후 모든 노드의 BF가 `{-1, 0, +1}`을 유지하기 때문에 별도의 회전이 발생하지 않는다.
- 결과 트리의 키 집합과 모양이 문제 2(BST 삭제 결과)와 동일해진다.

### 4-3. 출제 의도

- 삭제에서도 회전이 필요할 수 있음을 알리되, 이번에는 회전이 일어나지 않는 경계 케이스를 경험.
- BST 삭제 vs AVL 삭제의 알고리즘적 차이를 명시적으로 비교.

### 4-4. Claude 자체 부여 sub-prompt

```

(1, 2, 5, 8, 9)

각 삭제 단계에서 영향받은 조상들의 BF를 확인하고, 불균형이 발생하면
필요한 회전을 수행한 뒤 결과 트리를 도식화하라.
최종 트리의 세 가지 순회 결과도 함께 출력하라.
```

### 4-5. Claude 결과 (요약)

- 회전 발생: 없음.

- Post-order: `3 7`

## 문제 5. Python `bintrees`로 검증

### 5-1. 해답 — 소스 코드 `index.py`

> 소스 파일 본체: `../homework by Claude/index.py`

```python
from bintrees import BinaryTree, AVLTree

INSERT_SEQ = [5, 3, 7, 8, 2, 9, 1]
DELETE_SEQ = [1, 2, 5, 8, 9]


def collect(tree, order):
    # order: -1=pre, 0=in, +1=post (bintrees foreach 규약)
    out = []
    tree.foreach(lambda k, v: out.append(k), order)
    return out


def show(label, tree):
    print(label)
    print(f"In-order   {' '.join(str(k) for k in collect(tree, 0))}")
    print(f"Pre-order  {' '.join(str(k) for k in collect(tree, -1))}")
    print(f"Post-order {' '.join(str(k) for k in collect(tree, 1))}")
    print()


def build(tree_cls, insert_seq):
    tree = tree_cls()
    for k in insert_seq:
        tree.insert(k, None)
    return tree


def delete_all(tree, delete_seq):
    for k in delete_seq:
        tree.remove(k)
    return tree


def main():
    print(f"Insert sequence: {INSERT_SEQ}")
    print(f"Delete sequence: {DELETE_SEQ}")
    print("=" * 50)

    bst = build(BinaryTree, INSERT_SEQ)
    show("1. BST insert (5,3,7,8,2,9,1)", bst)

    delete_all(bst, DELETE_SEQ)
    show("2. BST after delete (1,2,5,8,9)", bst)

    avl = build(AVLTree, INSERT_SEQ)
    show("3. AVL insert (5,3,7,8,2,9,1)", avl)

    delete_all(avl, DELETE_SEQ)
    show("4. AVL after delete (1,2,5,8,9)", avl)


if __name__ == "__main__":
    main()
```

### 5-4. 핵심 기능 요약

- `bintrees.BinaryTree`: 평형 보정 없는 일반 BST.
- `bintrees.AVLTree`: 회전 기반 자가균형 BST.
- 공통 API: `insert(key, value)`, `remove(key)`, `foreach(func, order)` 등.
- `foreach(order=-1|0|+1)`이 그대로 pre/in/post-order 순회를 제공해 손계산 결과와 직접 비교 가능.
