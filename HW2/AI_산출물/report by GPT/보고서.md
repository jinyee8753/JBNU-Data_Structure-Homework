## 문제 1. BST insert (5, 3, 7, 8, 2, 9, 1)

### 1-1. 해답 - 단계별 도식

```
[Step 1] insert 5          [Step 2] insert 3          [Step 3] insert 7
    5                          5                          5
                              /                          / \
                             3                          3   7

[Step 4] insert 8          [Step 5] insert 2          [Step 6] insert 9
    5                          5                          5
   / \                        / \                        / \
  3   7                      3   7                      3   7
       \                    /     \                    /     \
        8                  2       8                  2       8
                                                             \
                                                              9

[Step 7] insert 1 - final
    5
   / \
  3   7
 /     \
2       8
/        \
1         9
```

### 1-2. 핵심 기능 요약

- BST 삽입은 현재 노드보다 작으면 왼쪽, 크면 오른쪽으로 이동해 빈 자리에 새 노드를 붙인다.
- 같은 값이 없다는 전제에서는 삽입 경로가 비교 결과만으로 결정된다.
- 평균 시간복잡도는 O(log n)이지만, 균형이 나쁘면 O(n)까지 나빠질 수 있다.

### 1-3. 문제 출제 의도

- BST의 좌소우대 규칙을 직접 적용하게 한다.
- 입력 순서가 트리 모양과 높이에 영향을 준다는 점을 확인하게 한다.
- 이후 AVL 삽입 결과와 비교할 기준 트리를 만든다.

### 1-4. GPT 입력 프롬프트

```
빈 Binary Search Tree에 5, 3, 7, 8, 2, 9, 1을 순서대로 삽입한다.
각 삽입 단계의 트리 모양을 ASCII 도식으로 보여주고,
최종 트리의 inorder, preorder, postorder 순회 결과를 계산해줘.
```

### 1-5. GPT 결과

- 최종 트리: 루트 5, 왼쪽 가지 3-2-1, 오른쪽 가지 7-8-9.
- In-order: `1 2 3 5 7 8 9`
- Pre-order: `5 3 2 1 7 8 9`
- Post-order: `1 2 3 9 8 7 5`

## 문제 2. BST delete (1, 2, 5, 8, 9)

### 2-1. 해답 - 단계별 도식

문제 1의 최종 BST에서 시작한다.

```
[start]                       [Step 1] delete 1
    5                              5
   / \                            / \
  3   7                          3   7
 /     \                        /     \
2       8                      2       8
/        \                              \
1         9                              9

[Step 2] delete 2             [Step 3] delete 5
    5                              7
   / \                            / \
  3   7                          3   8
       \                              \
        8                              9
         \
          9

[Step 4] delete 8             [Step 5] delete 9 - final
    7                              7
   / \                            /
  3   9                          3
```

### 2-2. 핵심 기능 요약

- 삭제할 노드가 leaf면 바로 제거한다.
- 자식이 하나면 그 자식을 삭제 노드 자리로 올린다.
- 자식이 둘이면 오른쪽 서브트리의 최솟값인 successor로 값을 대체한 뒤 successor를 제거한다.

### 2-3. 문제 출제 의도

- BST 삭제의 세 가지 경우를 구분하게 한다.
- 루트 삭제에서 successor 대체 과정을 확인하게 한다.
- 같은 삭제 시퀀스를 AVL에 적용했을 때와 비교할 기준을 만든다.

### 2-4. GPT 입력 프롬프트

```
문제 1에서 만든 BST에서 1, 2, 5, 8, 9를 순서대로 삭제한다.
두 자식이 있는 노드는 in-order successor로 대체한다고 가정한다.
각 삭제 단계의 ASCII 트리와 최종 inorder, preorder, postorder를 구해줘.
```

### 2-5. GPT 결과

- 최종 트리: 루트 `7`, 왼쪽 자식 `3`.
- In-order: `3 7`
- Pre-order: `7 3`
- Post-order: `3 7`

## 문제 3. AVL insert (5, 3, 7, 8, 2, 9, 1)

### 3-1. 해답 - 단계별 도식

BF는 `height(left) - height(right)`로 계산한다.

```
[Step 1] insert 5          [Step 2] insert 3          [Step 3] insert 7
    5                          5                          5
                              /                          / \
                             3                          3   7

[Step 4] insert 8
    5
   / \
  3   7
       \
        8

[Step 5] insert 9 - node 7에서 RR 불균형
    5
   / \
  3   7
       \
        8
         \
          9

left-rotate(7) 후:
    5
   / \
  3   8
     / \
    7   9

[Step 6] insert 2
      5
     / \
    3   8
   /   / \
  2   7   9

[Step 7] insert 1 - node 3에서 LL 불균형
      5
     / \
    3   8
   /   / \
  2   7   9
 /
1

right-rotate(3) 후 - final:
      5
     / \
    2   8
   / \ / \
  1  3 7  9
```

### 3-2. 핵심 기능 요약

- AVL 트리는 모든 노드의 BF를 -1, 0, 1 범위로 유지하는 자가 균형 BST이다.
- 삽입 후 불균형이 생기면 LL, RR, LR, RL 중 맞는 회전을 수행한다.
- 이 입력에서는 RR 1회, LL 1회가 발생한다.

### 3-3. 문제 출제 의도

- BST 삽입 후 균형 검사와 회전 보정이 어떻게 결합되는지 확인하게 한다.
- 같은 입력에서도 AVL은 BST보다 낮은 높이의 트리를 만든다는 점을 보여준다.
- 단일 회전 사례인 RR과 LL을 추적하게 한다.

### 3-4. GPT 입력 프롬프트

```
빈 AVL tree에 5, 3, 7, 8, 2, 9, 1을 순서대로 삽입한다.
각 단계에서 BF를 확인하고 불균형이 생기면 LL/LR/RL/RR 중 어떤 경우인지 표시해줘.
회전 전후 ASCII 트리와 최종 inorder, preorder, postorder도 알려줘.
```

### 3-5. GPT 결과

- Step 5: `7-8-9` 오른쪽 연속 증가로 RR 발생, `left-rotate(7)`.
- Step 7: `3-2-1` 왼쪽 연속 감소로 LL 발생, `right-rotate(3)`.
- In-order: `1 2 3 5 7 8 9`
- Pre-order: `5 2 1 3 8 7 9`
- Post-order: `1 3 2 7 9 8 5`

## 문제 4. AVL delete (1, 2, 5, 8, 9)

### 4-1. 해답 - 단계별 도식

문제 3의 최종 AVL에서 시작한다.

```
[start]                       [Step 1] delete 1
      5                              5
     / \                            / \
    2   8                          2   8
   / \ / \                          \ / \
  1  3 7  9                          3 7  9

[Step 2] delete 2             [Step 3] delete 5
      5                              7
     / \                            / \
    3   8                          3   8
       / \                              \
      7   9                              9

[Step 4] delete 8             [Step 5] delete 9 - final
      7                              7
     / \                            /
    3   9                          3
```

삭제 과정에서 모든 BF가 -1, 0, 1 범위에 남으므로 추가 회전은 발생하지 않는다.

### 4-2. 핵심 기능 요약

- AVL 삭제는 BST 삭제를 먼저 수행한 뒤 삭제 경로의 조상 노드 BF를 다시 검사한다.
- BF가 +-2가 되면 회전을 수행하지만, 이 시퀀스에서는 회전이 필요 없다.
- 최종 키 집합과 트리 모양은 문제 2의 BST 삭제 결과와 같다.

### 4-3. 문제 출제 의도

- AVL 삭제도 BST 삭제 규칙을 기반으로 한다는 점을 확인하게 한다.
- 삭제 후에는 삽입과 마찬가지로 균형 재검사가 필요함을 학습하게 한다.
- 회전이 항상 발생하는 것은 아니라는 경계 사례를 보여준다.

### 4-4. GPT 입력 프롬프트

```
문제 3에서 만든 AVL tree에서 1, 2, 5, 8, 9를 순서대로 삭제한다.
BST 삭제 규칙을 적용한 뒤 각 단계의 BF를 검사하고,
필요한 회전이 있으면 표시해줘. 최종 순회 결과도 계산해줘.
```

### 4-5. GPT 결과

- 회전 발생: 없음.
- 최종 트리: 루트 `7`, 왼쪽 자식 `3`.
- In-order: `3 7`
- Pre-order: `7 3`
- Post-order: `3 7`

## 문제 5. Python `bintrees`로 검증

### 5-1. 해답 - 소스 코드

소스 파일: `../homework by GPT/index.py`

```python
from bintrees import AVLTree, BinaryTree

INSERT_SEQ = (5, 3, 7, 8, 2, 9, 1)
DELETE_SEQ = (1, 2, 5, 8, 9)


def traversal(tree, order):
    result = []
    tree.foreach(lambda key, value: result.append(key), order)
    return result


def print_traversals(problem_number, tree):
    print(f"{problem_number}.")
    print("In-order  " + " ".join(map(str, traversal(tree, 0))))
    print("Pre-order " + " ".join(map(str, traversal(tree, -1))))
    print("Post-order " + " ".join(map(str, traversal(tree, 1))))
```

### 5-4. 핵심 기능 요약

- `BinaryTree`: 회전 보정이 없는 일반 BST.
- `AVLTree`: 삽입/삭제 후 자동으로 균형을 유지하는 AVL 트리.
- `foreach(func, order)`: `order=-1`은 pre-order, `0`은 in-order, `1`은 post-order 순회를 수행한다.

### 5-5. 문제 출제 의도

- 손계산 도식과 실제 라이브러리 출력이 같은지 검증하게 한다.
- BST와 AVL의 순회 결과 차이를 통해 트리 모양 차이를 확인하게 한다.
